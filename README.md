•Notes App 
The Notes App is a simple and efficient note-taking application built using Kotlin and Jetpack Compose. It allows users to create, edit, delete, and store notes using a local Room database.

•Technologies Used
1.Kotlin is used language for programming
2.Jetpack Compose For designing the ui in my android app program
3.MVVM Architecture for clean architecture
4.Room Database for storing the data in the offline mode when the device is not connected 

•Features
1.Add, Edit, and Delete Notes
2.Persistent Storage using Room Database
3.MVVM Architecture for clean and maintainable code
4.Simple and intuitive UI using Jetpack Compose
5.Lightweight and Fast Performance
